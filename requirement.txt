Password rules for new or changed passwords
- At least 8 characters
- At least one upper-case letter, one lower-case letter and one number

Sign-in rules
- 5 wrong attempts lock the username for 5 minutes
- Sessions end after 15 minutes of inactivity
- New or reset accounts must change the temporary password at first sign-in

Hosting requirements
- A modern browser (Chrome, Edge, Firefox, Safari)
- HTTPS or localhost (needed for secure password hashing)
- GitHub Pages with Source set to GitHub Actions

Note: if the repository is public, anyone can read this file. Delete it or
change the passwords in User Management before real use.
